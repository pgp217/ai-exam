# 파일럿 결과와 v2 수정 후보

계획은 [`docs/pilot.md`](pilot.md)에 있다. 이 문서의 숫자는 운영 DB의 파일럿 시험 데이터를 앱의 문항 분석 코드(`src/lib/analysis/items.ts`)와 설문 집계 코드로 계산한 값이다. 리허설 응시(`P-000`)는 뺐다. 개인을 알아볼 수 있는 내용은 적지 않는다.

> **해석 주의:** 응시자가 10명뿐이다. 정답률 50% 문항의 95% 오차범위가 ±31%p, 변별도 r의 표준오차가 약 0.38이다. 아래 내용은 "확정된 결론"이 아니라 "v2에서 고치고 다시 확인할 가설"이다. 다만 전원이 같은 답을 고르거나 대부분이 최저점을 받는 식의 극단적인 패턴은 인원이 조금 늘어도 바뀌기 어렵다.

## 1. 운영 개요

| 항목 | 결과 |
|---|---|
| 대상 / 응시 | 12명 / 10명 (응시율 83%), 마감일보다 일찍 마감 |
| 서술형 응답 | **선택으로 안내했다.** 참여자가 바빠 "서술형은 응시할 수 있는 사람만" 쓰도록 요청함. 문항별 답안 작성 5~6명 |
| 응시 시간 | 중앙값 4.2분, 범위 1.3~22.5분 (제한 시간 40분) |
| 채점 | 10명 전원 서술형 확정, 성장 피드백 승인·공개 |
| 오류 신고 | 0건 |
| 재응시 | 1건. 사유: "응시 링크 공유 문제로 10분밖에 남지 않음". 이전 응시를 보관한 뒤 같은 링크로 다시 응시했고, 설문에 "재응시가 가능해서 좋았다"는 의견이 남음 |

## 2. 응시 후 설문 (10명, 1~5점)

| 문항 | 평균 | 분포 (1·2·3·4·5) |
|---|---|---|
| 난이도 (1 매우 쉬움 ~ 5 매우 어려움) | 2.0 | 3·4·3·0·0 |
| 제한 시간 (1 많이 부족 ~ 5 많이 남음) | 4.3 | 0·0·0·7·3 |
| 문항 이해도 | 4.8 | 0·0·0·2·8 |
| 업무 관련성 | 4.8 | 0·0·0·2·8 |
| 화면 편의 | 4.9 | 0·0·0·1·9 |

자유 의견은 다섯 가지였다.
- 자기평가 문항은 바람직한 답이 뻔해 4·5점에 몰린다.
- 자기평가 일부가 신입사원 눈높이와 맞지 않는다.
- 상황 판단형 객관식의 정답이 확실한지 모르겠다.
- Q07("5요소 중 빠진 것") 정답이 애매하다.
- 재응시가 가능해서 좋았다.

**인터뷰** (리포트를 본 참여자 대상)
- 리포트에서 가장 먼저 본 것은 "동기 중 내 위치"였다.
- 성장 피드백은 "해 볼 만하다"고 했다.
- 서술형 2번은 지문의 숫자와 문장을 드래그해 복사·붙여넣기하며 답했다고 했다.

| 정답률 90% 이상 | 19문항 (그중 100%가 13문항) | 사람을 가르지 못하는 문항이 대부분 |

### 서술형 3문항 (답안을 쓴 사람만, 기준별 확정 점수 1~4점)

서술형은 선택으로 안내했다. 그래서 빈 답안(4명은 3문항 모두, 1명은 2문항)은 시험의 문제로 보지 않는다. 아래 통계는 답안을 쓴 사람만으로 계산했다(E1 6명, E2·E3 각 5명). 같은 이유로 실전 점수·종합 점수·등급, 그리고 "서술형 짧음" 신뢰도 신호는 이번 파일럿에서 해석하지 않는다.

| 기준 | 평균 | 1점 비율 |
|---|---|---|
| E1 5요소 / 구체성 / 출력 형식 / 보안 | 3.2 / 3.8 / 2.5 / 3.5 | 0 / 0 / 2 / 0 (6명 중) |
| E2 의심 지점 식별 | 4.0 | 0/5 (전원 만점) |
| E2 확인 방법 | 2.8 | 0/5 |
| **E2 논리 비약 탐지** | **1.8** | **3/5** |
| **E2 사용 판단** | **2.0** | **3/5** |
| E3 위험 인식 / 대안 제시 / 협업 태도 | 2.6 / 2.8 / 2.4 | 0 / 0 / 1 (5명 중) |
| **E3 규정 확인** | **1.6** | **3/5** |

- **문항이 묻지 않은 기준:** 답안을 쓴 사람 중에서도 세 기준(E2 논리 비약·사용 판단, E3 규정 확인)만 절반 넘게 1점(언급 없음)이고, 나머지 기준은 대부분 2점 이상이다.
  - E2는 "의심할 부분 3가지와 확인 방법"만 묻는데, 기준표는 논리 비약과 사용 판단까지 요구한다.
  - E3는 "어떻게 대응할지"만 묻고 회사 규정 확인은 요구하지 않는다.
- **너무 쉬운 기준:** E2 의심 지점 식별은 5명 모두 4점이다. 4점 기준("퇴사율 주장")이 논리 비약 기준과 내용이 겹치는 점도 함께 정리가 필요하다.
- **AI-담당자 일치율:** 12개 기준 모두 90~100%다. 담당자가 AI 점수를 거의 그대로 확정했기 때문에, 이 숫자를 AI 채점이 정확하다는 독립적인 근거로 보기는 어렵다.

### 자기평가와 응답 신뢰도

- **자기평가 평균:** 3.1~4.2점
- **과대평가 경향** (자기평가 > 실제): 결과 검증 +26, 윤리·보안 +22
- **과소평가 경향:** 책임 있는 사용 -30, 업무 적용 -24, 반복 개선 -22
- **응답 신뢰도:** "신뢰 불가" 8명, "주의" 2명
  - 걸린 신호: 빠른 응답 7명, 서술형 짧음 6명(서술형을 선택으로 안내한 영향), 서술형 붙여넣기 5명, 자기평가 무변별 1명
  - 붙여넣기 신호는 인터뷰에서 확인했듯 지문을 인용하려고 복사한 경우에도 걸린다(오탐).
  - 빠른 응답 신호는 객관식이 너무 쉬운 탓이 크다.

**반영 현황:** 우선순위 "높음"(1~3)과 Q02·Q06·Q07·Q17 수정을 `NEWHIRE-AI-v2`에 반영했다. 근거와 문항별 검토는 [`docs/item-set-v2.md`](item-set-v2.md). 자기평가(8), 붙여넣기 오탐(9), 제한 시간(10), 블라인드 채점(11)은 다음 차례다.

## 5. 정리

- **잘 된 것:**
  - 응시 흐름과 화면: 이해도 4.8, 편의 4.9, 오류 신고 0건
  - 운영 기능: 재응시 사유 기록, 설문
  - 리포트의 동기 위치와 성장 피드백에 대한 반응
- **고칠 것:** 측정 도구로서의 변별력
  - 객관식이 너무 쉽고 정답 위치에 규칙이 있다.
  - 서술형은 문항이 묻지 않은 기준 때문에 일부 점수가 실제 역량을 반영하지 못한다.
- **다음 단계:** v2로 고친 뒤 새 응시자 10명 이상으로 2차 파일럿을 한다. 이번에는 서술형도 필수로 안내한다. 확인할 것은 지식 점수 분산, 문항별 변별도, 서술형 기준별 분포, 실제 응시 시간이다.
