# Power BI 역량 대시보드 설계서

시험 결과를 부서·기수 단위로 모아, 교육 담당자가 **어떤 역량 교육을 어느 부서에 먼저 열지** 정하도록 돕는 대시보드다.
이 문서는 화면 설계와 계산식이고, 화면은 Power BI Desktop에서 직접 만든다.

## 1. 대시보드가 답할 질문

| 질문 | 화면 |
|---|---|
| 전체적으로 어느 수준인가 | ① 요약 |
| 어느 부서가 어느 역량에서 약한가 | ② 부서 × 역량 히트맵 |
| 가장 약한 역량은 무엇인가 | ③ 취약 역량 순위 |
| 어떤 교육을 먼저 열어야 하나 | ④ 교육 우선순위 |
| 스스로 잘한다고 착각하는 역량은 무엇인가 | ⑤ 자기평가 vs 실제 |
| 교육을 바꾼 뒤 기수별로 나아졌나 | ⑥ 기수 추이 (선택) |

## 2. 데이터

### 받는 곳
- **연습용 가상 데이터:** `docs/bi/sample/`에 CSV 3개가 있다. 5개 부서, 3개 기수, 202명이다. 실제 사람이 아니다. 다시 만들려면 `npx tsx scripts/bi-sample.mts`를 실행한다.
- **실제 데이터:** 관리자 화면 **결과 목록 → BI 내보내기**에서 표마다 CSV를 받는다. 채점이 끝난 응시만 들어간다. 리허설(`P-000`)이나 가상 응시자(`SIM-`)는 "제외할 사번"에 적어서 뺀다.

### 표 3개

**응시자** (1인 1행)

| 열 | 설명 |
|---|---|
| 응시자ID | 대상자 id의 해시(`R-` + 8자리). 이름·사번은 넣지 않는다 |
| 시험, 문항세트, 부서, 기수 | 부서·기수가 비어 있으면 `미지정` |
| 응시일, 응시시간_분, 응답신뢰도 | 응시일은 한국 시간 기준 |
| 총점, 등급, AI활용유형, 지식점수, 실무점수 | 0~100점 |
| AI 이해, AI 활용, AI 책임 | 상위요인 점수 |
| 약점1, 약점2 | 점수가 가장 낮은 역량 2개 |

**역량점수** (응시자 × 역량 8개)

| 열 | 설명 |
|---|---|
| 응시자ID, 역량코드 | M1~M8 |
| 점수 | 0~100. 객관식, 그리고 서술형이 있는 역량은 서술형 점수와의 평균 |
| 자기평가, 자기평가차이 | 자기평가(0~100) − 점수. 양수면 스스로를 높게 본 것이다 |
| 자기평가판정 | 차이가 기준 이상이면 `과대평가`, 이하면 `과소평가`, 그 사이는 `적정` |
| 교육대상 | 점수가 60점(등급 B의 하한) 미만이면 1 |

**역량** (8행, 차원 표)

| 열 | 설명 |
|---|---|
| 역량코드, 역량, 상위요인, 설명 | |

### 개인정보 원칙
- BI 파일에는 이름·사번·연락처, 답안 원문, AI 채점 근거를 넣지 않는다.
- **5명 미만 집단은 화면에 표시하지 않는다.** 응시자ID만 있어도 작은 부서의 한 기수를 고르면 누구인지 알 수 있기 때문이다. 아래 `[역량 평균(표시)]` 측정값이 이 규칙을 맡는다.
- 결과는 교육 기획에만 쓰고, 개인 평가나 인사 판단에는 쓰지 않는다. 대시보드 첫 화면에 이 문구를 넣는다.

## 3. Power BI 준비

1. **가져오기:** 홈 → 데이터 가져오기 → 텍스트/CSV로 세 파일을 가져온다.
   - 파일 원본(인코딩)이 `65001: 유니코드(UTF-8)`인지 확인한다.
   - **데이터 변환**을 눌러 열 형식을 확인한다. 점수류는 10진수, 응시일은 날짜, 교육대상은 정수다.
2. **관계:** 모델 보기에서 확인한다. 자동으로 만들어지지 않았으면 직접 만든다.
   - `응시자[응시자ID]` 1 → * `역량점수[응시자ID]`
   - `역량[역량코드]` 1 → * `역량점수[역량코드]`
   - 교차 필터 방향은 둘 다 **단일**이다.
3. **정렬:**
   - `역량[역량]`을 선택하고 열 도구 → 열 기준 정렬 → `역량코드`. M1~M8 순서로 보이게 한다.
   - 등급은 글자 순서로는 A+가 A 뒤에 온다. 응시자 표에 계산 열을 만들고 `등급`을 이 열 기준으로 정렬한다.
     ```DAX
     등급순서 = SWITCH('응시자'[등급], "A+", 1, "A", 2, "B+", 3, "B", 4, "C+", 5, "C", 6, "D+", 7, "D", 8)
     ```
4. **측정값 표:** 홈 → 데이터 입력으로 빈 표 `_측정값`을 만들고, 아래 측정값을 모두 여기에 둔다.

## 4. 측정값 (DAX)

```DAX
응시자 수 = DISTINCTCOUNT('응시자'[응시자ID])
평균 총점 = AVERAGE('응시자'[총점])

-- 역량점수 표 기준 인원 (부서·기수 필터가 관계를 따라 내려온다)
인원 = DISTINCTCOUNT('역량점수'[응시자ID])
역량 평균 = AVERAGE('역량점수'[점수])

-- 5명 미만 집단은 빈칸으로 둔다
역량 평균(표시) = IF([인원] >= 5, [역량 평균])

-- 부서 필터만 풀고 기수·시험 필터는 유지한 비교 기준
전체 평균 = CALCULATE([역량 평균], REMOVEFILTERS('응시자'[부서]))
전체 대비 = IF([인원] >= 5, [역량 평균] - [전체 평균])

교육 대상 인원 = IF([인원] >= 5, SUM('역량점수'[교육대상]))
교육 대상 비율 = IF([인원] >= 5, DIVIDE(SUM('역량점수'[교육대상]), [인원]))

과대평가 비율 =
VAR judged = CALCULATE(COUNTROWS('역량점수'), NOT ISBLANK('역량점수'[자기평가판정]))
VAR over = CALCULATE(COUNTROWS('역량점수'), '역량점수'[자기평가판정] = "과대평가")
RETURN IF([인원] >= 5, DIVIDE(over, judged))

자기평가 평균 = AVERAGE('역량점수'[자기평가])
```

- 서식: 점수는 소수 1자리, 비율은 백분율 0자리로 둔다.
- `교육 대상 인원`과 `교육 대상 비율`에도 5명 규칙을 넣었다. 집단이 작으면 인원수만으로도 개인이 드러날 수 있기 때문이다.

## 5. 화면

모든 화면 상단에 **기수·시험·부서 슬라이서**를 같은 위치에 둔다. 보기 → 슬라이서 동기화로 묶는다.

### ① 요약
- **카드 3개:** `[응시자 수]`, `[평균 총점]`, 전체 `[교육 대상 인원]`
- **등급 분포:** 묶은 세로 막대. 축은 `응시자[등급]`(등급순서로 정렬), 값은 `[응시자 수]`
- **AI 활용 유형:** 도넛 또는 가로 막대. 범례는 `응시자[AI활용유형]`
- **안내 문구(텍스트 상자):** "결과는 교육 기획에만 씁니다. 5명 미만 집단은 표시하지 않습니다."

### ② 부서 × 역량 히트맵 (핵심 화면)
- **행렬 시각적 개체:** 행은 `응시자[부서]`, 열은 `역량[역량]`, 값은 `[전체 대비]`
- **조건부 서식 → 배경색:** 규칙 대신 그라데이션을 고르고, 가운데 값을 사용한다.
  - 최소는 빨강, 가운데(0)는 흰색, 최대는 파랑
  - 빨간 칸이 그 부서가 전체보다 약한 역량이다.
- **도구 설명:** `[역량 평균]`과 `[인원]`을 추가한다.
- 기수 슬라이서로 한 기수만 고르면 작은 부서는 빈칸이 된다. 5명 규칙이 동작하는 것이다.

### ③ 취약 역량 순위
- **가로 막대:** 축은 `역량[역량]`, 값은 `[역량 평균(표시)]`, **오름차순 정렬**(가장 약한 역량이 위)
- **상수 선:** 분석 창 → 상수 선을 60에 둔다. 교육 대상 기준이다.
- 옆에 같은 막대를 `[과대평가 비율]`로 하나 더 두면, "약한데 자신 있는" 역량이 함께 보인다.

### ④ 교육 우선순위
- **분산형 차트:** 세부 정보는 `역량[역량]`, X축은 `[교육 대상 비율]`(얼마나 심각한가), Y축은 `[교육 대상 인원]`(얼마나 많은가)
- **평균 선:** 분석 창 → X축 평균 선, Y축 평균 선. 화면이 네 칸으로 나뉜다.
  - **오른쪽 위:** 심각하고 대상도 많다 → 1순위 전사 교육
  - **오른쪽 아래:** 심각하지만 대상이 적다 → 해당 부서 맞춤 교육
  - **왼쪽 위:** 넓게 퍼져 있지만 가볍다 → 짧은 온라인 과정
  - **왼쪽 아래:** 지금은 보류
- **표:** `역량[역량]`, `[교육 대상 인원]`, `[교육 대상 비율]`, `[과대평가 비율]`. 교육 대상 인원 내림차순으로 정렬한다.
- 부서 슬라이서를 고르면 "그 부서에 먼저 열 교육"이 된다.

### ⑤ 자기평가 vs 실제
- **묶은 가로 막대:** 축은 `역량[역량]`, 값은 `[자기평가 평균]`과 `[역량 평균(표시)]`
- **행렬:** 행은 `응시자[부서]`, 값은 `[과대평가 비율]`. 조건부 서식은 데이터 막대
- 과대평가가 많은 역량은 스스로 교육이 필요하다고 느끼지 않는다. 그래서 공지보다 사례 중심 안내가 필요하다는 해석을 덧붙인다.

### ⑥ 기수 추이 (선택)
- **꺾은선형:** X축은 `응시자[기수]`, Y축은 `[역량 평균(표시)]`, 범례는 `역량[역량]`
- 필터로 역량을 2~3개만 남긴다. 예: 프롬프트 설계, 반복 개선
- 교육 과정을 바꾼 기수 앞뒤로 점수가 달라졌는지 본다. 원인을 단정하지 말고 "함께 나타났다"로 쓴다.

## 6. 만든 뒤 확인할 것 (가상 데이터 기준)

가상 데이터에는 아래 패턴을 일부러 넣었다. 대시보드에서 이 패턴이 보이면 계산식과 관계가 맞게 만들어진 것이다.

시드 2026으로 만든 `docs/bi/sample` 기준 값이다.

- **히트맵:** 가장 진한 빨강은 두 칸이다.
  - 인사팀의 도구 지식: 전체보다 약 23점 낮다.
  - 영업팀의 결과 검증: 전체보다 약 15점 낮다.
- **히트맵:** 경영지원팀의 프롬프트 설계는 약 10점 낮다.
- **히트맵:** 마케팅팀과 영업팀의 윤리·보안은 약 5~7점 낮다.
- **기수 슬라이서:** 인사팀은 12명이다. 2025 상반기(2명)나 2026 상반기(3명)를 고르면 빈칸이 되고, 2025 하반기(7명)는 보인다.
- **자기평가:** 영업팀의 과대평가 비율이 약 34%로 가장 높다. 다른 부서는 10~21%다.
- **기수 추이:** 2026 상반기에 프롬프트 설계(약 61~64 → 76)와 반복 개선(약 66~67 → 78)이 오른다.
- **교육 대상:** 전체 202명 × 8개 역량 가운데 527칸이 60점 미만이다.

보이지 않으면 관계의 방향, 역량 정렬 열, 측정값의 표 이름부터 확인한다.

## 7. 포트폴리오에 넣기

- **캡처:** ② 히트맵, ④ 우선순위, ⑥ 기수 추이 3장. 화면마다 "가상 데이터"를 표시한다.
- **설명 문장 예:**
  - 시험 결과를 부서 × 역량으로 집계해, 전체 대비 약한 역량을 히트맵으로 드러냈다.
  - 교육 대상 비율(심각도)과 인원(규모)으로 교육 우선순위를 네 칸으로 나눴다.
  - BI 파일은 이름·사번 없이 해시 ID로 내보내고, 5명 미만 집단은 측정값에서 숨기도록 설계했다.
- **실제 파일럿(10명):** 부서가 대부분 비어 있어 부서 비교는 할 수 없다. 전체 분포와 역량 순위만 쓰고, 부서·기수 화면은 가상 데이터로 시연했다고 밝힌다.
